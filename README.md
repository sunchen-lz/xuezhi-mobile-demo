# 学智律行前端 Demo

这是独立的静态浏览器原型，目标设备为 Android 手机、Android 平板、iPhone 和 iPad。使用虚构案件和材料，不连接案件 API、授权服务、OCR 或 Grok；导入、识别、转换、同步和归档均为浏览器内的演示状态。

直接打开 `index.html` 即可预览。可用桌面浏览器开发者工具切换到 390px 手机宽度或 768px 以上平板宽度检查响应布局。原生 Flutter 客户端仍是正式产品目标。

品牌导航使用 2026-10-20 确认的案卷夹 Logo 定稿裁切图 `assets/brand-lockup.png`。

已包含案件分类/筛选、案件详情、材料导入入口、OCR 待校对状态、转换件演示、材料预览、审阅笔记、建议采纳和用户确认定稿流程。
